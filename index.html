WifiPasswordViewer

Nur zu Lernzwecken (Educational Purpose Only)

Diese Seite zeigt den Code nur an, sie führt ihn nicht aus. Eine Webseite darf aus Sicherheitsgründen nicht auf gespeicherte WLAN-Passwörter zugreifen, weder auf dem iPhone noch am PC.

index.js

const wifi = require('wifi-password');

wifi.getWifiInfo().then(info => {
  console.log('Wi-Fi Networks:');
  info.forEach(network => {
    console.log(`SSID: ${network.ssid}`);
    console.log(`Password: ${network.password}\n`);
  });
}).catch(error => {
  console.error('Error:', error);
});

Warum läuft das nicht im Browser?

Der Befehl require(...) gehört zu Node.js, einem Programm, das JavaScript direkt auf dem Computer ausführt. Im Browser gibt es require nicht, und das Paket wifi-password fragt das Betriebssystem ab, was nur ein Programm auf dem eigenen Rechner darf.
